What's inside

Built for the way
you actually work.

Not a stripped-down free tier. Everything ships on day one.

⚡
Reverse tunnel

Expose localhost to the internet instantly. HTTPS, real domain, no configuration. Works behind any NAT or corporate firewall.

core
🪝
Webhook relay

Built-in adapters for Paystack, Flutterwave, and GitHub. Signature verification, event storage, one-click replay of missed events.

african payments
📊
Live dashboard

Real-time request log, webhook inspector with raw payload view, handoff panel. No page refresh — updates as traffic flows.

localhost:5555
🔄
Load balancer

Round robin, least connections, or random across multiple local backends. Health checks automatically remove dead targets.

built-in
📡
Offline cache

When your internet drops, namd serves cached API responses. Keep coding. Set HTTP_PROXY=localhost:7777 in your app.

for bad connections
🔋
Live handoff

Battery dying mid-demo? Transfer your tunnel to a trusted peer's machine. Same URL. Zero downtime. They accept, you close your laptop.

Get started

Three steps.

No account on a foreign startup's platform. Just install, register once, run.

go install github.com/gabbykarry/namd/cmd/namd@latest
namd auth register --name yourname --email you@example.com
namd start
